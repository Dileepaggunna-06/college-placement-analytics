# College Placement Analytics

A full-stack web application for analyzing college placement data and visualizing placement statistics through an interactive dashboard.

## 🚀 Features

- View total students
- View total companies
- Calculate average package
- Find highest and lowest package
- Analyze students selected by company
- Analyze students selected by branch
- Calculate average package by company
- Calculate average package by branch
- View highest CGPA student
- View complete student placement data
- Interactive charts and dashboard

## 🛠️ Technologies Used

### Frontend
- React.js
- Vite
- Recharts
- JavaScript
- HTML
- CSS

### Backend
- Python
- Flask
- Pandas
- Flask-CORS

### Data
- CSV
